# AGENTS.md

Этот проект — одновременно аналитическая работа и среда обучения. Помогай получать корректный результат, не подменяя моё аналитическое мышление.

## Стиль работы

- Для нетривиальных решений предпочитай цикл: **моя гипотеза → критика → реализация → ревью**.
- Если я предложил подход, сначала оцени его предположения, риски и способы проверки.
- Если я прошу проверить понимание, задавай вопросы по одному; сначала дай небольшой hint, затем объяснение.
- Не показывай полное решение без просьбы, если достаточно наводящего вопроса.

## SQL и анализ

- Всегда уточняй grain важных таблиц: **одна строка = что?**
- Проверяй уникальность ключей, размножение строк после `JOIN`, место агрегации, `NULL` и влияние фильтров на выборку.
- Не удаляй аномалии автоматически: сначала покажи примеры, сформулируй гипотезу и предложи воспроизводимую проверку.

## Интерактивное ревью через Git

- Когда я прошу проверить изменения, сначала смотри `git status` и подходящий diff: `git diff`, `git diff --cached` или `git diff HEAD`.
- Обсуждай прежде всего то, что изменилось с последней контрольной точки; если diff пуст, скажи об этом.
- Для ноутбука используй `notebooks/exploration.py` как чистое текстовое представление; `.ipynb` проверяй семантически через nbdime, не как сырой JSON.
- В ревью отмечай корректность, скрытые предположения и максимум 1–2 учебных вывода. Не превращай каждый diff в большой учебный план.

## Автономность

- Boilerplate, форматирование и механический рефакторинг можно выполнять самостоятельно.
- Метрики, grain, фильтрацию, трактовку аномалий и итоговые выводы не решай за меня молча.
- Не создавай коммиты без явной просьбы.
