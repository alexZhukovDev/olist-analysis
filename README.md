# Olist Brazilian E-Commerce Analysis

Портфолио-проект по анализу продаж, качества доставки и клиентского опыта
бразильского маркетплейса Olist.

Главный вопрос исследования: **почему заказы покупателей из Rio de Janeiro (RJ)
опаздывают заметно чаще, чем заказы из São Paulo (SP), и на каком этапе доставки
возникает разрыв?**

## Основные результаты

- Среди доставленных заказов с известными датами **6,77%** доставлены позже
  обещанной календарной даты.
- Средняя оценка снижается с **4,29** для своевременно доставленных заказов
  до **2,11** при задержке на 4–7 дней.
- Доля опозданий составляет около **12,1% в RJ** против **4,5% в SP**.
- Разница сохраняется внутри сопоставимых диапазонов расстояния. Для заказов
  одного продавца из SP на расстоянии 300–500 км маршруты SP → RJ опаздывают
  примерно в 13% случаев, а SP → SP — менее чем в 5%.
- Почти весь разрыв среднего срока между этими маршрутами возникает
  **после передачи заказа перевозчику**.

## Методика

- SQL-запросы выполняются в DuckDB.
- Стоимость заказа агрегируется из `order_items` до grain
  **одна строка = один заказ**.
- Опоздание определяется по календарным датам:
  фактическая дата доставки позже обещанной.
- Для одного заказа сохраняется последний валидный отзыв.
- Координаты ZIP-префикса агрегируются медианой.
- Расстояние рассчитывается по формуле гаверсинусов и интерпретируется как
  приблизительное прямолинейное расстояние.
- Анализ расстояний ограничен заказами с одним продавцом.

## Ограничения

- В датасете нет идентификаторов перевозчиков и промежуточных логистических
  событий.
- Прямолинейное расстояние не равно дорожному маршруту; в геоданных есть
  отдельные аномальные координаты.
- Анализ показывает связи, но не доказывает причинность.
- GOV включает стоимость товаров и доставки, но не является показателем
  прибыли или чистой выручки Olist.

## Запуск

1. Скачать
   [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
2. Поместить CSV-файлы в `Brazilian E-Commerce/data/raw/`.
3. Создать окружение и установить зависимости:

```powershell
cd "Brazilian E-Commerce"
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

4. Открыть `notebooks/exploration.ipynb` и выполнить ячейки сверху вниз.
